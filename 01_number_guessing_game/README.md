# 🎯 Number Guessing Game (C++)

A simple console-based number guessing game written in C++.

## 🚀 How It Works
- Enter a maximum number between **1 and 500**
- The program generates a **random number**
- Try to guess the number
- The game tells you if your guess is **too high** or **too low**
- When you guess correctly, you can **play again or exit**
