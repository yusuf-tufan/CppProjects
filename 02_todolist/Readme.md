# 📝 C++ Console To-Do List Application

A lightweight and efficient terminal-based task management system written in C++. This project demonstrates fundamental programming concepts such as dynamic memory management with vectors, custom data structures, and formatted console output.

## 🚀 Features

- **Full CRUD Operations:** Create, Read, Update, and Delete tasks easily.
- **Smart Table Rendering:** A custom algorithm that wraps long text into multiple rows to keep the terminal view organized.
- **Input Validation:** Robust handling of invalid numeric inputs and character limits to prevent application crashes.
- **Bulk Actions:** Option to clear the entire task list with a single command.
